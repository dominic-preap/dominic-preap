### 🧭 About

I ship across the whole stack — **NestJS** for GraphQL/REST APIs, **React**/**Next.js** on the web, **React Native**/**Expo** on mobile — and run the cloud infrastructure underneath it: servers, deployments, CI/CD, the works. Mostly on small teams where I'm the one person covering frontend, backend, infra, and everything in between.

- 🏗️ **Backend:** NestJS services with a typed GraphQL layer, schema design, relational databases, background jobs
- 🎨 **Frontend:** React apps built to stay readable past year one — component systems, data fetching, accessibility
- 📱 **Mobile:** React Native for iOS & Android from one codebase, offline-first data, native modules, release management
- ☁️ **Server & DevOps:** Docker, CI/CD pipelines, zero-downtime deploys, TLS/reverse proxies, backups, logs & alerts
